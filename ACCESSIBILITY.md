# Accessibility

We aim to make Lorenz usable through clear interaction and to improve accessibility as barriers are identified. We do not claim conformance to a particular accessibility standard.

## Current support and limitations

Lorenz supports keyboard navigation in its wheel and a batch manager alongside its drag gesture. The [user guide](docs/USER_GUIDE.md) describes keyboard controls and available interaction paths. Availability varies by desktop and integration.

Compatibility with every assistive technology, platform and workflow has not been verified. Consult the project documentation for tested platforms and known limitations.

## Report a barrier

Please [open an issue](https://github.com/Chaos-Tic/Lorenz/issues/new/choose) and describe the task, the barrier, the application version, operating system, desktop environment and assistive technology if relevant. Avoid including personal or confidential information. Security vulnerabilities should be reported privately as described in [SECURITY.md](SECURITY.md).
