# Code of conduct

We want Lorenz discussions to be welcoming, constructive and respectful. Treat people with dignity; give and receive feedback in good faith. Harassment, discrimination, threats, personal attacks and publishing another person's private information without consent are not acceptable.

This applies to project spaces including issues, pull requests and discussions. Maintainers may edit or remove disruptive content, close conversations or restrict participation when necessary.

To raise a conduct concern, contact the maintainers through a repository issue without posting sensitive details; ask for a private way to share them. For security vulnerabilities, use the private reporting route in [SECURITY.md](https://github.com/Chaos-Tic/Lorenz/blob/main/SECURITY.md). Maintainers will consider reports and respond as availability permits.
